# 医美维权困局之下，如何让“美”不再伴随风险
基于中国裁判文书网2024-2025年公开的108份医美纠纷有效裁判文书，分析医美维权难点、高危项目及胜诉关键的数据新闻。

## 项目结构
| 文件夹/文件                | 作用说明                                                                 |
|---------------------------|--------------------------------------------------------------------------|
| `/docs/yimei_news.md`     | 核心数据新闻文档，含完整分析、案例及图表引用                              |
| `/charts/`                | 所有可视化图表：<br>- HTML格式：交互图表（如核心结论概览图）<br>- PNG格式：静态统计图表（如胜诉率扇形图） |
| `/README.md`              | 项目说明文档（当前页面）                                                |

## 图表查看说明
1. **HTML交互图**：在 `/docs/yimei_news.md` 中点击图表链接，会跳转至 `/charts/` 文件夹中的HTML文件，可直接预览交互效果；
2. **PNG静态图**：在 `/docs/yimei_news.md` 中直接显示，点击图片可查看高清版；
3. 若图表加载失败，刷新页面或检查网络，仍有问题可联系仓库作者。

## 数据说明
- 数据来源：中国裁判文书网2024年1月1日-2025年6月30日公开的108份有效医美纠纷裁判文书；
- 地域范围：不含港澳台地区，仅统计中国大陆省级行政区案件；
- 隐私保护：案例中消费者姓名均为化名，关键信息已脱敏。
